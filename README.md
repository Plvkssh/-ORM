# Learning Management System (LMS)

Учебная платформа для управления курсами, студентами и учебными материалами. 
Система предоставляет полный цикл обучения: от записи на курсы до оценки результатов.

## 🚀 Технологический стек

### Бэкенд
- **Java 17** - основной язык разработки
- **Spring Boot 3** - фреймворк для создания приложений
- **Spring Data JPA** - работа с базой данных
- **Spring Security** - аутентификация и авторизация
- **Hibernate** - ORM для работы с PostgreSQL

### База данных
- **PostgreSQL 16** - основная база данных
- **Testcontainers** - для изолированных тестов

### Документация
- **OpenAPI 3** + **Swagger UI** - документация API

### Тестирование
- **JUnit 5** - фреймворк для тестирования
- **MockMvc** - тестирование REST контроллеров
- **AssertJ** - утверждения для тестов

## 📋 Требования к окружению

- **JDK 17** или выше
- **Maven 3.9** или выше
- **PostgreSQL 16** (локально) или **Docker** (для тестов)
