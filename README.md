# ORM

Учебная платформа для управления курсами, студентами и учебными материалами.

## 🚀 Технологический стек

### Бэкенд
- Java 17
- Spring Boot 3
- Spring Data JPA
- Spring Security
- Hibernate

### База данных
- PostgreSQL 16
- Testcontainers

### Документация
- OpenAPI 3 + Swagger UI

### Тестирование
- JUnit 5
- MockMvc
- AssertJ

## 📋 Требования к окружению

- JDK 17 или выше
- Maven 3.9 или выше
- PostgreSQL 16 (локально) или Docker (для тестов)
